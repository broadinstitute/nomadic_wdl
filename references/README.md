# Reference genomes

Reference genome files `nomadic` needs at runtime. These are baked into the
Docker image (see `../Dockerfile`) so the WDL doesn't call `nomadic download`
at runtime — see the file layout `nomadic` expects in its own
`src/nomadic/download/references.py`.

The `67` in these filenames is **not** a genome assembly version — it's
PlasmoDB/VectorBase's own release counter (these VEuPathDB-family sites cut a
new numbered release every few months with updated annotations, while the
underlying assembly, e.g. "3D7" or "PEST", stays the same across many
releases).

## Pf3D7 (Plasmodium falciparum 3D7)

- Source: [PlasmoDB](https://plasmodb.org), release 67
- Species/strain: Pfalciparum 3D7
- Genome assembly annotation version (embedded in the FASTA headers): `2020-09-01`
- Raw download URLs (release 67):
  - FASTA: `https://plasmodb.org/common/downloads/release-67/Pfalciparum3D7/fasta/data/PlasmoDB-67_Pfalciparum3D7_Genome.fasta`
  - GFF: `https://plasmodb.org/common/downloads/release-67/Pfalciparum3D7/gff/data/PlasmoDB-67_Pfalciparum3D7.gff`
- Derived files in this folder (generated by `nomadic download`, not raw downloads):
  - `PlasmoDB-67_Pfalciparum3D7.standard.gff` — standardized GFF
  - `PlasmoDB-67_Pfalciparum3D7_Genome.lowcomplexity_mask.bed` — low-complexity mask
  - `PlasmoDB-67_Pfalciparum3D7_Genome.fasta.fai` — samtools faidx index
- **Important correction applied to the FASTA:** `nomadic download` automatically
  reverts `Pf3D7_08_v3:549685` from G to C, restoring the wild-type (alanine)
  allele at DHPS A437 instead of the sulfadoxine-resistance-associated glycine
  variant (see `src/nomadic/download/corrections.py` in the `nomadic` repo).
  If this FASTA is ever replaced with a fresh, unmodified download straight
  from PlasmoDB, this correction must be reapplied.
- Added to this repo: 2026-09-10

## AgPEST (Anopheles gambiae PEST)

- Source: [VectorBase](https://vectorbase.org), release 67
- Species/strain: Agambiae PEST
- Raw download URLs (release 67):
  - FASTA: `https://vectorbase.org/common/downloads/release-67/AgambiaePEST/fasta/data/VectorBase-67_AgambiaePEST_Genome.fasta`
  - GFF: `https://vectorbase.org/common/downloads/release-67/AgambiaePEST/gff/data/VectorBase-67_AgambiaePEST.gff`
- **Status: not yet added.** This directory currently only holds a `.gitkeep`
  placeholder. Once downloaded, add these files with the exact names below and
  the Dockerfile's existing `COPY references/AgPEST/ ...` step will pick them
  up automatically, with no Dockerfile changes needed:
  - `VectorBase-67_AgambiaePEST_Genome.fasta`
  - `VectorBase-67_AgambiaePEST.gff`
  - `VectorBase-67_AgambiaePEST.standard.gff`
  - `VectorBase-67_AgambiaePEST_Genome.lowcomplexity_mask.bed`
